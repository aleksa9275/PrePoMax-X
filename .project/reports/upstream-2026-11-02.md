## New community port — reported capabilities, not local validation

Moritz Schuettler announced [PrePoMac](https://prepomax.discourse.group/t/first-prepomax-macos-version/3773)
on 22 October. Its current [repository README](https://github.com/moritzschuettler/prepomac)
describes a native Apple Silicon desktop app, an Apple Silicon ZIP release and
experimental Linux support. It reports 77/79 API scripts passing. These are
author claims read from primary sources; no download/build/test was performed.

The implementation uses Avalonia Windows Forms compatibility, a VTK-compatible
OpenGL renderer, native OpenCASCADE/gmsh helpers and SPOOLES CalculiX, with optional
Code_Aster. It explicitly reports different meshes from Windows, unavailable
QuadWild, two failed API cases and an unresolved roughly 50% solver stiffness
disagreement on a bike-frame model. Its renderer/mesher/backend choices differ
from our still-open parity decisions. The current README is newer than the
announcement (which originally said there was no download); use it for current
reported packaging state.

Architectural inference: assess this code and its fixtures before duplicating
desktop compatibility work. It may accelerate delivery, but its existence and
reported tests do not establish our numerical/native-tool/four-target acceptance
or authorize replacing our renderer/mesher/solver policy. No contact, adoption,
dependency installation or architecture decision occurs in this review.
